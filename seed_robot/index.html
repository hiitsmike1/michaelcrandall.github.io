Autonomous Robot Mission - Team Project

Description:

Collaborated in an 8-person team to design and build a robot to autonomously complete a predetermined task. The task included navigating and aligning on a mission site, analyzing the mission site, place and bury a seed based on results, extract a sample from the mission site, and navigate a randomly set up obstacle course without any human intervention.

- Implemented sensor-based obstacle detection and control logic using an Arduino microcontroller
- Assisted in hardware wiring, motor driver integration, and testing for mission completion
- Gained experience in embedded programming, teamwork, and system integration
- Used machine learning to predict different orientations of the mission accurately
