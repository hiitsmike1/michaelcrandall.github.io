4-bit ALU with RTL Logic - Personal Project

Description:

Designed, implemented, and tested a 4-bit Arithmetic Logic Unit (ALU) entirely from discrete components using resistor-transistor logic (RTL). By not using integrated circuits, this project demonstrates low-level logic design, transistor-level hardware implementation, and manual bus managment

- Utilized over 160 individual NPN BJT transistors and 270 resistors to construct the necessary logic gates for mathematical and bitwise operations
- Implemented 7 distinct hardware operations including Addition, Subtraction, bitwise OR/AND/NOT, and Shift Left/Right (SHL/SHR)
- Made a 3x7 multiplexer paired with 7 tri-state buffers to safely drive each output to the bus.
